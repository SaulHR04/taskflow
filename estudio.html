Guía de Estudio: jwt-auth-demo

Estructura, carpetas y componentes explicados al detalle

📌 Conceptos Generales e Infraestructura

.github/workflows/*.yml CI / CD

Configuración de GitHub Actions para integración y despliegue continuo.

  • Builds automáticos: Levanta un servidor Linux en cada push o PR.
  • Testing y Linter: Ejecuta npm install, chequeo de tipos, linter y build[cite: 5].
  • Despliegue: Publica la app automáticamente en GitHub Pages usando build:pages[cite: 5].
node_modules/ npm

Carpeta donde npm descarga todas las dependencias del proyecto[cite: 2, 5].

  • Ignorada en Git: Incluida explícitamente en el archivo .gitignore[cite: 2].
  • Regenerable: Se restaura completamente ejecutando npm install.
vite.config.ts Bundler

Configuración del empaquetador y servidor de desarrollo Vite.

  • Plugins: Habilita Fast Refresh para React mediante @vitejs/plugin-react[cite: 5, 7].
  • Ruta Base (base): Adapta subcarpetas para despliegues en GitHub Pages[cite: 1, 5].
  • Build: Define alias de ruta y la carpeta de salida dist[cite: 2].

🌐 src/config & 🛡️ src/context

src/config/apiUrl.ts Config

Contiene la constante API_URL con la dirección base del servidor en AWS CloudFront para centralizar peticiones HTTP[cite: 1].

src/context/AuthContext.tsx State

Administra el estado global de sesión de la aplicación[cite: 16].

  • Valida la existencia previa de un token JWT almacenado[cite: 16].
  • Provee funciones globales login() y logout()[cite: 16].

⚓ src/hooks

useAuth.ts Hook

Acceso directo al estado y funciones expuestas por el AuthContext.

useProjects.ts Hook

Consulta la lista de proyectos manejando estados de carga (loading), error (error) y recarga (refetch).

useProjectForm.ts Hook

Controla el estado, captura y validaciones del formulario de proyectos.

useTasks.ts Hook

Obtiene y actualiza la lista de tareas recibidas desde el servidor backend.

🧩 src/components

ProjectForm.tsx UI

Formulario para la creación de proyectos con validaciones de nombre (mínimo 3 caracteres) y estados de envío[cite: 12].

ProjectList.tsx UI

Muestra el catálogo de proyectos con retroalimentación visual de carga (CircularProgress) y alertas de error[cite: 13].

TaskForm.tsx UI

Formulario para añadir tareas vinculadas a un proyecto mediante select, campos de título, descripción, prioridad y fecha[cite: 14].

TaskList.tsx UI

Lista de tareas que destaca visualmente su estado y prioridad usando etiquetas de colores (Chip de Material UI)[cite: 15].

📄 src/pages & 🔌 src/service

LoginPage.tsx Page

Vista para inicio de sesión. Captura datos de acceso, invoca la autenticación y realiza la navegación hacia el Dashboard[cite: 18].

DashboardPage.tsx Page

Panel principal privado[cite: 17]. Integra dentro de tarjetas (Paper) los componentes de listas, formularios y botón de cierre de sesión[cite: 17].

httpClient.ts Service

Instancia de Axios que adjunta de forma automática el encabezado Authorization: Bearer <token> a las solicitudes.

authService.ts Service

Consume el endpoint /login y administra la persistencia del token JWT dentro del localStorage.

projectService.ts / taskService.ts Service

Contienen las llamadas HTTP (GET y POST) para consultar y crear proyectos y tareas en el backend.

📄 Archivos Raíz de src/

main.tsx Core

Punto de entrada de React 19[cite: 10]. Monta el componente raíz <App/> sobre el elemento HTML #root en modo estricto[cite: 4, 10].

App.tsx Core

Orquestador global[cite: 9]. Aplica el tema visual MUI, inicializa el AuthProvider y define el mapa de rutas navegables[cite: 9].

ProtectedRoute.tsx Core

Guardián de navegación[cite: 11]. Redirige a usuarios no autenticados a /login y autoriza el paso a las páginas privadas con <Outlet/>[cite: 11].

types.ts / vite-env.d.ts TypeScript

Definición de interfaces TypeScript compartidas (modelos de datos) y declaración de tipos para las variables de entorno de Vite.
